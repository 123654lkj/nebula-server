# 知识库总入口（黑曜石 / Obsidian Vault）

> 本目录是 **L1 权威正文**。星枢（Nebula）是 **L3 语义索引**。
> 冲突时：**听笔记原文**，向量块只是线索。

## 30 秒上手

| 优先级 | 场景 | 去哪 |
|:---:|------|------|
| 1 | 改架构 / 查事实 | 本 vault 对应笔记 **原文** |
| 2 | 模糊回忆「以前咋弄的」 | 星枢 `POST /ask` → 命中 `vault:*` 后 **readback 回读** |
| 3 | 密码 / API key | **禁止**写进笔记与向量；用密码管理器 |

## 目录约定

```
notes/
├── HOME.md              ← 你在这
├── PROJECT.md           ← 章程

├── 01-用户画像/         ← 人 / 环境画像
├── 02-密码与安全/       ← 操作手册（无明文密钥）
├── 03-API与模型/        ← 模型与接入约定
├── 04-项目笔记/         ← 实施记录
├── 05-临时记录/         ← 会过期的快照
└── 团子学习/            ← 大体量资料（默认同步白名单，不 bulk）
```

## 与星枢的分工

| | 黑曜石笔记 L1 | 星枢 L3 |
|--|--------------|---------|
| 角色 | 权威正文 | 语义索引 + 会话碎片 |
| 写入 | 人/Agent 编辑 `.md` | `memory/add` 或 vault 同步 |
| 冲突 | **听笔记** | chunk 降权 / supersede |

同步命令：`npm run sync` 或 `python scripts/vault_to_nebula_sync.py`
