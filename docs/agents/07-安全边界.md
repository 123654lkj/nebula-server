# 07 · 安全边界

## 1. 铁律

```text
密钥 / token / 私钥 / 会话 cookie
  → 只进 L4 密码本或密钥管理
  → 禁止进入 L2 向量正文与 query 日志明文
  → L2 最多存指针：服务名、条目名、轮换策略
```

## 2. 写入拦截（服务端必做）

启发式示例（实现自定，需持续加强）：

- 高熵长串、`sk-` / `ghp_` / `BEGIN PRIVATE KEY` 等形态  
- 密码字段 JSON  
- 疑似连接串 `user:pass@host`  

命中 → **拒绝 add**，返回明确错误，引导走 secrets API。

## 3. 日志与导出

- access log 不落 query 中的密钥形态  
- 备份与导出默认脱敏  
- 公开仓库 / issue **禁止**粘贴生产记忆库  

## 4. 多租户与网络（原则）

- 默认绑定最小暴露面（本机或受信网络）  
- 鉴权：若对局域网外服务，必须有 token/mTLS  
- 本设计不规定具体防火墙规则  

## 5. 供应链

- 模型与依赖固定版本或锁文件  
- 不在仓库提交 `.env` 与 session 文件
